# SIGINT-101 UX audit — 2026-11-02

Target: **origin/ux-polish @345fbfb** (lands first). Spot-compared against origin/main, which moved
to **e2dc239** during the audit: the brief said c22f7d9, and main has since gained exam diagrams and
the tty1 kiosk. Hand-over is 2026-11-08, so the findings are ordered as a fix-sprint backlog.

## Verdict

**Not ready to hand over: 7 S0, 13 S1.** The three worst:

1. **The exam soft-locks.**
   - On 139 of the 409 pool questions the Commit button sits below 480 px. On 22 of them it is
     entirely off-screen, and `.exam` is `overflow:hidden`.
   - The practice exam always serves the first unanswered question and has no skip.
   - 89% of drawn sheets contain a question that can never be committed.
2. **Lesson text is buried.**
   - On L11–L28 the eyebrow reprints the 81–139-word concept at 13 px caps on both frame and explain.
     That squeezes the body to 7–82 px. On L27 the explain reveal is 7 px, so effectively invisible.
   - Decoder-lesson instructions get a 35 px slot. L13's get 0 px.
3. **First hands-on steps ask for controls that do not exist.**
   - Missing controls: L1 station list, L2 gain, L4 V3 switch, L6/L7 1090 MHz, L8 presets.
   - Tune ± changes only the label: 3 taps gave 100.3 → 100.6, axis unchanged, **0** `/api/tune`.

**Measurement setup.** Every number comes from a **forced 800×480** viewport
(`Emulation.setDeviceMetricsOverride`) with the cache disabled. Rendering used nomad-b's Chromium 156
(headless, scrollbars visible, matching `deploy/kiosk/start-kiosk.sh`), against a server on the
droplet. The droplet has no SDR, so every instrument shows its honest no-radio/503 state.

**Coverage.**
- 645 screen measurements: 215 screens × 3 themes.
- 409 × 3 exam-card fits.
- A 9-flow learner walk with real pointer taps.
- **Observed** = rendered and measured. **Inferred** = from code or computed style, where live radio
  would be needed.

## S0 — blocks hand-over, breaks a CLAUDE.md rule, or traps/misleads

### S0-1 Exam card, review and practice exam don't fit; the sim soft-locks (observed)
- **Evidence.**
  - `ux_flow13_exam_card.png` is the first card a fresh learner sees (T0A01), a real render.
  - `ux_dark_exam-review-T1D01.png` is a real server-rendered review: the question is 0 px and "Next card" sits at 569 px, fully off-screen.
  - `ux_dark_exam-card-T1D01.png` is the same pool text swapped into the live card: Commit at 606 px.
  - On T0A01:
    - "Commit answer" bottom **504 px**, 69% visible, clipped by `section.exam` (`overflow:hidden`,
      cutting 24 px).
    - The question is squeezed into its own 46 px scroller with a default unstyled scrollbar. That
      scrollbar is also the only neutral-grey light in red-night.
  - `examfit.py` (study card) and `simfit.py` (practice-exam card) swap each of the 409 questions
    into the live card's real CSS. The server's own review page was also rendered for every question.
  - **Answer card:** Commit is off-screen on **139/409**.
    - It is **fully hidden on 22**, worst bottom **663**. Examples: T1C03, T1C10, T1D01, T1D05–09,
      T1E11, T1F08, T2A04, T2A06, T2B14, T2C06, T2C07.
    - The sim card is identical: 139 off-screen, 22 hidden, worst 662.
  - **Review page:**
    - "Next card"/"Next question" is off-screen on **47**. It is fully hidden on 8: T1D01, T1D06,
      T1D07, T1D09, T2A06, T2C06, T7B06, T8C07.
    - The question **collapses to 0 px on 71** and is partly hidden on 78 more.
  - **Practice exam:**
    - It always serves the first unanswered question.
    - It has no skip, and Retake exists only on the results page.
    - Drawing one question per group, **P(sheet has ≥1 fully hidden Commit) = 0.89**, and P(≥1
      clipped Commit) = 1.00.
  - Main has the same failure (`main_dark_exam-card.png`, Commit 504).
- **Learner impact.**
  - The learner picks an answer and cannot commit it.
  - In the sim they are stuck on that question for good: Back → `/exam` → sim link → the same
    question.
- **Fix sketch.**
  - Give `.exam` the lesson pattern: a scrolling body (question + chips, `overflow-y:auto`) and a
    pinned `.stage-foot`-style footer for the hint and Commit/Next.
  - Remove the question's own scroller.
  - Move the sim link into the footer.
  - Add Skip/Abandon to the sim.
  - Gate: `examfit.py`/`simfit.py` show 0/409 off-screen.
- **Cost.** S (CSS + template), plus S for sim skip.

### S0-5 Waterfall smoothing blends bins (inferred, RF invariant)
- **Evidence.**
  - `canvas.waterfall` computes `image-rendering: auto` on all 72 waterfall screens.
  - The buffer is one pixel per bin (`drawRow` sets `width = bins`), but CSS stretches it to 100%.
    - FM default: 160 bins → 758 px (4.7× bilinear).
    - L9 433.92 ± 1 MHz: 16 bins at 47×.
    - Rows are squashed by 0.57 vertically.
  - Only `.gallery__img` has `pixelated`.
  - The coordinator's `instrument-honesty` branch (:8032) already computes `pixelated`.
- **Learner impact.** Gradients between bins look like measured signal. This breaks the CLAUDE.md
  invariant "one pixel per rtl_power bin — no interpolation".
- **Fix sketch.** `.waterfall { image-rendering: pixelated; }`, then HIL with a lit carrier.
- **Cost.** S.
